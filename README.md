# Stocking

개인용 주식 차트 도우미. 토스증권 Open API 시세로 국내·미국 종목 차트를 보여주고,
자동 지지/저항선, 초보자용 설명, 뉴스 요약, 옵션·실적·경제지표 일정, 질문에 답하는 AI 를 한 화면에 띄운다.

- 개인용. 토스 시세·야후 데이터는 다시 배포하지 않는다. 서버는 기본으로 이 PC(127.0.0.1)에서만 열린다
- 주문 기능은 없다 (토스 주문 API 를 일부러 안 붙였다)
- 자동 선·차트 신호·차트 패턴은 검증해 보니 **예측력이 없었다** (아래 '검증'). '사라/팔라'가 아니라 차트를 읽는 도구로 쓴다

## 실행

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
copy .env.example .env   # 키 채우기
.\run.ps1                # http://127.0.0.1:8800
```

| 키 | 용도 | 없으면 |
|---|---|---|
| `TOSS_CLIENT_ID/SECRET` | 시세·종목정보·보유종목 | 데모 데이터 |
| `NAVER_CLIENT_ID/SECRET` | 국내 뉴스 | 국내 뉴스 없음 |
| `FINNHUB_API_KEY` | 미국 뉴스, 실적 발표 일정, 비교 종목 후보 | 미국 뉴스·실적 일정 없음 |
| `OPENAI_API_KEY` | 요약·구조 읽기·질문 탭·투자 논리·판단 기록 | 기사 목록·숫자만 |
| `TELEGRAM_BOT_TOKEN/CHAT_ID` | 알림을 폰으로 | 화면 알림만 |

- 토스 키: 토스증권 WTS → 설정 → Open API. **허용 IP에 내 공인 IP 등록** 필수 (안 하면 403)
- 회사 정보·옵션·미국 지수는 키 없이 야후에서 받는다 (몇 분 늦음)
- 모델·알림 기준값은 `.env.example` 참고. `.\run.ps1 -Lan` 은 집 와이파이에서만 (`APP_PASSWORD` 필요)

## 기능

**차트**
- 토스 실시간 체결(WebSocket → SSE). 1분~1시간, 일·주·월·년봉. 일봉은 상장 이후 전부, 왼쪽으로 끌면 더 받아온다
- 마우스를 올리면 시가·고가·저가·종가. 미국 종목은 원 | $ 전환
- **+ 추가**: 지지/저항선, 추세선, 채널, 52주 최고·최저, 이평선·볼린저·RSI·MACD 등 지표, 차트 신호
- **직접 긋기**: 추세선·수평선·층 채널(⫽, 찍을 자리 추천). 관심종목이면 닿을 때 알림

**자동으로 그은 선** (`backend/analysis.py`)
- 현재가 근처에서 2번 이상 닿은 가격대, 스윙 고·저점을 이은 추세선, 채널. 선을 누르면 실제로 닿은 지점과 횟수
- 최근에 깨진 추세선은 흐리게 남기고, 추세선은 오늘 뒤로 20봉 더 늘여 그린다
- 토스 일봉은 주간거래까지 합친 장통합이라 거래 없는 시간에 튄 긴 꼬리가 섞인다 → 선을 찾을 때만 잘라서 본다

**종목 탭**
- **한눈에 보기**: 회사 정보, 옵션이 예상하는 움직임(만기별 ±%, 콜/풋 비율), 비교 종목(AI 가 고르고 숫자는 코드가 계산), 구조 읽기(AI 가 차트 모양을 풀어 씀)
- **차트 패턴**: 이중 바닥·헤드앤숄더·삼각수렴·깃발형·컵앤핸들 등 8종, 무효선·거래량 동반 표시
- **차트 신호**: 크로스·52주 신고가·추세선/채널 돌파 등. 같은 종목 과거 성적을 '아무 날 샀을 때'와 나란히
- **뉴스**: 국내(네이버)·미국(Finnhub), 관련 없는 기사 거르기 + 요약, **왜 움직였지?**
- **내 규칙**: 지지선 근처 매수 구간 · 저항선 목표 · ATR 손절 · 손익비를 AI 없이 계산으로 대조
- **투자 논리**: 왜 샀는지를 기둥·틀렸다고 볼 조건·기다리는 이벤트로 정리해 두고, 그동안의 가격·실적·뉴스로 기둥마다 유지/약화/깨짐 점검
- **판단 기록**: 아래 참고

**오른쪽 패널** (경계를 끌어서 폭 조절)
- **내 투자·관심·최근 본**: 토스 계좌 보유종목(차트에 내 평단), 관심종목 현재가·가까운 지지/저항까지 거리, 쉼표로 여러 개 추가
- **시장**: 토스 실시간 ETF + 야후 지수·선물·금리·원자재·환율·코인, AI 시장 요약, 달러↔원 계산기
- **달력**: 미국 경제지표(CPI·고용·FOMC…)와 실적 발표를 **한국 날짜·한국 시간**으로 (장 마감 후 실적 → 한국 다음 날 새벽)
- **알림**: 지지/저항 근접·돌파, 급등락(3→6→9%, 이유를 뉴스에서 찾음), 차트 신호. 화면·브라우저·텔레그램
- **질문**: AI 가 앱 도구(시세·선·내 규칙·뉴스·회사 숫자·옵션·특정 가격 근처 이력·투자 논리)를 골라 써서 답한다.
  숫자는 도구가 준 것만. 종합 의견을 물으면 '20거래일 동안 시장보다 강함·중립·약함'으로 말하고 판단 기록에 남긴다.
  관심종목·알림을 바꾸는 일은 제안만 하고 확인 버튼을 눌러야 실행

## 검증 (`research/`, 정리: `research/REPORT.md`)

과거 각 시점에서 그때까지 데이터만으로 선·신호를 만들고 이후를 본다. 대조군 = 같은 조건의 '근거 없는 선'·'아무 날'.

| 질문 | 결과 |
|---|---|
| 자동 선에 닿으면 튕기나? (40종목·8년) | 수평선은 대조군과 같음. 추세선 지지는 오히려 2.3~2.5%p 더 잘 깨짐 (경계선 유의) |
| 닿은 횟수가 많으면 더 잘 지켜지나? | 아니오 → 별점 표시 삭제 |
| 깨진 뒤 그 방향으로 이어지나? | 아니오. '아무 날 진입'과 비슷 |
| 매물대·라운드넘버·이평선·피벗·피보나치·주봉은? | 보정 후 유의하게 나은 방식 없음 |
| 차트 패턴 돌파 뒤 오르나? (80종목) | 8종 모두 20봉 초과수익 0 근처 |
| 내 규칙대로 사면? | 그냥 들고 있기보다 낫지 않음. 200일선 위에서만 사는 변형(F2)은 기본 규칙보다 나았지만 들고 있기와 차이 유의하지 않음 (2018년 이후 확인 진행 중) |

```powershell
python -m research.backtest_lines   # 자동 선 + 대조군
python -m research.methods          # 13가지 방식 비교
python -m research.confirm          # 확증: 탐색에 안 쓴 40종목
python -m research.patterns_backtest
```

## 판단 기록 (`backend/judgments.py`)

AI 의 종목 판단이 맞는지 **앞으로 쌓이는 기록으로** 채점한다 (과거로는 못 본다 — 모델이 그 뒤 일을 이미 학습했다).

- 매주 월요일 아침, 고정 종목군(중형·고변동 100 + 나스닥 100)에 '20거래일(참고 5일) 동안 SPY 보다 강함/중립/약함 + 확신'을 묻는다
- 조건 비교: 숫자만 / + 회사 숫자 / + 기사. 기록과 모델 입력 원문은 `judgments/` 에 덧붙이기만 한다
- 출발 가격 = 판단 뒤 첫 미국 정규장 처음 30분 평균. 서버가 켜져 있으면 10분마다 채운다
- 기준과 바꾼 이력은 `judgments.py` 맨 위. **첫 채점이 나온 뒤에는 기준을 바꾸지 않는다**
